# BlueHarvest AI - Spawn Pricing & Packaging Model

## Commercial Valuation Formula
Commercial spawn transactions require accurate estimation based on verified point counts combined with packing and oxygenation costs:

$$\text{Total Price (₹)} = (\text{Spawn Count} \times ₹0.025) + ₹50.00$$

- **Unit Spawn Rate**: ₹0.025 per individual spawn.
- **Flat Packing Overhead**: ₹50.00 per batch container (covers polythene bag, oxygen cylinder charge, salinized water prep).

## Layout & Baseline Rules
- Total Spawn and Price metric tiles must maintain equal padding and synchronized font size (`24px`, weight `900`).
- Price values must use the Indian Rupee symbol (`₹`) formatted with two decimal places.
