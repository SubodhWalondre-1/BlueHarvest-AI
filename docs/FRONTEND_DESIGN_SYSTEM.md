# BlueHarvest AI - Frontend Design System & Tokens

## Core Palette
- **Brand Primary**: `#1D70F7` (Electric Ocean Blue)
- **Success / Healthy**: `#10B981` (Emerald Green)
- **Warning / Moderate**: `#F59E0B` (Amber Orange)
- **Danger / Loss**: `#DC2626` (Crimson Red)
- **Surface Light**: `#FFFFFF` / Surface Background: `#F8FAFC`
- **Surface Dark**: `#0F172A` / Surface Dark Secondary: `#1E293B`
## Component System
- **DualFishLoader**: Custom SVG animation representing circular fish swimming motion.
- **Status Badges**: Pill badges with high-contrast text and semi-transparent tinted backgrounds.
- **Metric Cards**: Paired metric tiles with synchronized font sizing and baseline alignment.
