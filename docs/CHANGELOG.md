# Changelog

All notable changes to the BlueHarvest AI project will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.7.0] - 2026-08-31
### Added
- Core backend FastAPI application scaffold.
- SQLAlchemy 2.0 ORM models and Alembic database migration setup.
- P2PNet model architecture specifications and dataset collection standards.
## [0.8.0] - 2026-09-30
### Added
- P2PNet computer vision point-detection inference runtime.
- JWT and Google OAuth2 authentication endpoints.
- Batch session persistence, automated telemetry, and metrics aggregation.
- Comprehensive automated pytest test suite.

## [0.9.0] - 2026-10-18
### Added
- React 19 + Vite frontend application with light/dark theme manager.
- WebRTC camera capture stream and drag-and-drop file upload.
- Batch history feed with chronological groupings.
